Backup e rollback

Antes da promoção

Exportar o D1 remoto, registrar deployment atual, conferir migrations pendentes e validar R2/bindings. Nunca promover com migrations desconhecidas.

npm run db:hml:list
npx wrangler deployments list --env hml
# export/backup remoto antes de produção

Rollback

Rollback do Worker não reverte D1. Reversão de banco precisa de estratégia explícita e backup anterior.

npx wrangler rollback <VERSION_ID>
# D1: restaurar somente com procedimento aprovado
